# QR Transfer

Transfer any file between devices using QR codes — no internet, no accounts, no cables required.

## Live

| | |
|---|---|
| **Encoder** | https://a5tr1k.github.io/qr-tansfer/qr-encoder.html |
| **Decoder** | https://a5tr1k.github.io/qr-tansfer/qr-decoder.html |

## Usage

1. Open the **Encoder** and select any file
2. Scan the generated QR codes in order using the **Decoder** on another device
3. The file is reassembled and verified automatically — then download it

Works with any file type. SHA-256 integrity check is built in.

## Files

```
qr-encoder.html   — select a file, generates QR codes
qr-decoder.html   — scans QR codes via camera, downloads the file
```
